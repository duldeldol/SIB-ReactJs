# 📚 BookStore — Studi Kasus React JS

Aplikasi web toko buku online (*BookStore*) yang dikembangkan menggunakan **React JS (Vite)**, **Bootstrap 5**, dan **Font Awesome**. Dibuat untuk memenuhi tugas **Pertemuan 1 Studi Independen Bersertifikat (SIB) - NF Academy x Kampus Merdeka**.

## 🚀 Fitur Utama

1. **Halaman Home**:
   - **Hero Section**: Sorotan buku best-seller *Atomic Habits* oleh James Clear (cover buku lokal, rating 4.9/5, sinopsis, tombol CTA beli & jelajahi).
   - **Katalog Buku (Product List)**: Grid kartu buku populer Indonesia (*Filosofi Teras, Laut Bercerita, The Psychology of Money, Bumi Manusia, Sebuah Seni untuk Bersikap Bodo Amat, Gadis Kretek*) dengan filter kategori, harga, dan rating.

2. **Halaman Team**:
   - Profil tim pengembang dan kurator buku (*Keanu Reeves, Cillian Murphy, Ryan Gosling, Zendaya*) dengan foto lokal dan tautan media sosial.

3. **Halaman Contact**:
   - Kolom Kiri: Informasi kontak dan lokasi toko (Kampus STT Terpadu Nurul Fikri, WhatsApp hotline, email resmi, jam operasional).
   - Kolom Kanan: Formulir kirim pesan interaktif dengan validasi state React.

4. **Navigasi Single Page Application (SPA)**:
   - Berpindah antar halaman (*Home, Team, Contact*) secara instan menggunakan state React dan hash routing tanpa refresh browser.

5. **Tema Desain & Footer**:
   - Tema warna **Deep Emerald Teal (`#0f766e`)** yang elegan dan nyaman untuk membaca.
   - Footer multi-kolom bertema gelap (*Dark Theme*) lengkap dengan hak cipta resmi mahasiswa.

## 💻 Cara Menjalankan Project

1. Clone repositori ini:
   ```bash
   git clone https://github.com/duldeldol/SIB-ReactJs.git
   cd SIB-ReactJs
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server lokal:
   ```bash
   npm run dev
   ```

4. Buka di browser:
   ```
   http://localhost:5173
   ```
